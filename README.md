
# FinClear
SENG 513 – Group 8

Web-Based Systems – Fall 2026

## Project Overview


Welcome to **FinClear**, our financial management application. This repository will contain both the frontend and backend for this full-stack project. The following stack will be used for implementation

#### Frontend
- React Vite
- TypeScript
- Tailwind CSS
- shadcn/ui
- shadcn/ui Charts
- Zod
- React Query

#### Backend
- Node.js
- RESTful API
- node-postgres

#### Database
- PostgreSQL

#### Bank Data Integration
- Plaid API
- OAuth 2.0

#### Authentication and Security
- JWT-based authentication
- Password hashing
- HTTPS/TLS
